ASHENROOT — Koder Edition

PLAYABLE FILE
Open Ashenroot_Koder_Playable.html in Koder's browser/preview mode.
It is self-contained and does not require external libraries or image files.

CONTROLS
A/D or Left/Right: move
Space, W, or Up: jump
K: attack
L: dash
P: pause
Touch controls are included on screen.

ART ASSETS
The generated_images folder contains original optional concept art:
- ashenroot_pilgrim.png
- ashenroot_moss_demigod.png
- ashenroot_bell_demigod.png
- ashenroot_cavern_background.png

The current playable HTML renders its animated characters with Canvas so it still works as one standalone file in Koder.
